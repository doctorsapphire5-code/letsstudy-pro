Introduction

The LetsStudy Pro API allows applications to access platform resources such as users, courses, payments and learning content.

Base URL

https://api.letsstudy.pro/v1

Response format

{ "success": true, "data": {}, "message": "Request successful" }

Authentication

Send your API key using the Authorization header.

Authorization: Bearer YOUR_API_KEY

Never expose secret API keys in public frontend JavaScript or Git repositories.

API Endpoints

GET /users ›

Retrieve a list of users.

GET /v1/users Authorization: Bearer YOUR_API_KEY
GET /users/{id} ›

Retrieve a specific user.

GET /v1/users/{id} Authorization: Bearer YOUR_API_KEY
POST /users ›

Create a new user.

POST /v1/users Content-Type: application/json Authorization: Bearer YOUR_API_KEY { "name": "John", "email": "john@example.com" }
GET /courses ›

Retrieve available courses.

GET /v1/courses Authorization: Bearer YOUR_API_KEY
GET /courses/{id} ›

Retrieve one course.

GET /v1/courses/{id} Authorization: Bearer YOUR_API_KEY
POST /payments ›

Create a payment request.

POST /v1/payments Content-Type: application/json Authorization: Bearer YOUR_API_KEY { "amount": 10000, "currency": "TZS", "reference": "ORDER-001" }
DELETE /users/{id} ›

Delete a user resource.

DELETE /v1/users/{id} Authorization: Bearer YOUR_API_KEY

Common Parameters

Parameter Type Description
id string Unique resource ID.
limit integer Number of results.
page integer Pagination page.
search string Search query.

JavaScript Example

const response = await fetch( "https://api.letsstudy.pro/v1/courses", { headers:{ "Authorization": "Bearer YOUR_API_KEY", "Content-Type": "application/json" } } ); const data = await response.json(); console.log(data);
