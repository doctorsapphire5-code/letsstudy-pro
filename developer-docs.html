🚀 Quick Start

Create an API key, authenticate your application and make your first request.

1. Create an API key

Open API Keys and generate a key with the permissions your application needs.

2. Authenticate

Authorization: Bearer YOUR_API_KEY

3. Make your first request

const response = await fetch( "https://api.letsstudy.pro/v1/courses", { headers:{ "Authorization": "Bearer YOUR_API_KEY" } } ); const data = await response.json(); console.log(data);
Your application is now ready to communicate with the LetsStudy Pro API.

🔌 API Development

The API provides versioned endpoints for users, courses, resources, payments and other platform services.

Base URL: https://api.letsstudy.pro/v1

Example

GET /v1/courses Authorization: Bearer YOUR_API_KEY
API Dashboard → Complete API Reference → Manage API Keys →

📦 SDK Development

SDKs provide reusable tools for interacting with LetsStudy Pro services.

Example SDK initialization
