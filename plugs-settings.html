Plugin Settings

Configure your plugin, updates, marketplace visibility, security and advanced options.

General Settings
Basic information used by your plugin.
Update Settings
Control how plugin updates are delivered.
Automatic Updates Allow users to automatically receive new plugin versions.
Beta Updates Allow users to install experimental releases.
Update Notifications Notify users when a new version is available.
Marketplace Settings
Control how your plugin appears in the marketplace.
Marketplace Visibility Show this plugin publicly in the marketplace.
Allow Reviews Allow customers to rate and review the plugin.
Security Settings
Protect your plugin and its users.
Code Verification Require plugin code verification before publishing.
Security Scanning Scan plugin packages for suspicious or unsafe code.
Block Unverified Versions Prevent installation of versions that have not passed review.
Notification Settings
Choose which plugin events should send notifications.
New Sale Receive notifications when someone purchases your plugin.
New Review Receive notifications when a customer reviews your plugin.
Plugin Approval Receive a notification when your plugin is approved.
Advanced Settings
Advanced options for developers.

Danger Zone

Deleting a plugin removes its local settings and metadata from this dashboard.
