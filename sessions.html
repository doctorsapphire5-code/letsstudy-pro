Security information

Firebase Authentication manages authentication sessions through secure tokens. A normal HTML page cannot reliably enumerate every active Firebase session/device. If you need full multi-device session management, LetsStudy Pro should create a server-side session registry using Cloud Functions or another trusted backend.
